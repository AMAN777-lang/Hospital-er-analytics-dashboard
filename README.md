# Hospital Emergency Room Analytics Dashboard

This project presents a comprehensive dashboard built from hospital emergency room (ER) data, focusing on daily patient trends, wait times, and satisfaction scores. It enables healthcare professionals and analysts to monitor operational performance and identify areas for improvement.

## 📊 Dashboard Features

- **Daily ER Patient Volume**  
  Area sparkline visualizing daily patient counts to highlight busy periods and seasonal fluctuations.

- **Average Wait Time Trend**  
  Area sparkline showing daily changes in patient wait times, helping identify bottlenecks or staffing issues.

- **Patient Satisfaction Score**  
  Area chart tracking satisfaction trends, useful for correlating service quality with operational load.

- **Pivot Report Summary**  
  - Distinct patient count per day  
  - Average wait time and satisfaction score  
  - Admission status breakdown  
  - Age group distribution  
  - Gender and department-wise analysis  
  - Attendance and delay status

## 🧰 Tools Used

- **Excel**: Dashboard creation, pivot tables, sparklines  
- **Python (Pandas)**: Data cleaning and preprocessing  
- **Minitab** *(optional)*: Statistical validation and visualization

## 📁 Files Included

- `Dashboard.xlsx`: Main dashboard with visualizations and pivot reports  
- `Hospital Emergency Room Data.csv`: Raw ER data (too large to upload here)  
- `README.md`: Project overview and usage guide

## 🚀 How to Use

1. Open `Dashboard.xlsx` in Excel.
2. Navigate through the sheets to explore daily trends and pivot summaries.
3. Use filters to drill down by age group, department, or admission status.
4. For deeper analysis, preprocess the CSV data using Python and update the dashboard.

## 📈 Insights

- Peak ER traffic observed on specific dates (e.g., 5-Aug, 10-Aug, 20-Aug).
- Wait times and satisfaction scores show inverse correlation on busy days.
- Admission rates vary across age groups and departments.
